# Video prompts for the website

Make each video from one of the render images (image to video), so the towers keep their real shape. Do not use text only. Use 16:9, and keep each clip 5 to 10 seconds.

When a video is finished, save it with the file name shown and upload it to the `tower-ar` folder on GitHub. The website shows it by itself.
